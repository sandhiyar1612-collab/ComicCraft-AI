## Live Demonstration Quick-Start
To conduct a live demonstration:
1. Start the server:
   ```bash
   python run.py
   ```
2. Open your browser to [http://127.0.0.1:8000](http://127.0.0.1:8000).
3. Follow the steps detailed in [Demo_Steps.md](file:///d:/comic/08_Project_Demonstration_Phase/Demo_Steps.md).
